# Parrot vs Zombie 🦜🧟

Game phòng thủ tháp (Tower Defense) phong cách Plants vs Zombies phiên bản Parrot vs Zombie.

## Tính năng
- **Chơi tự do (Standalone Mode)**: Đã tắt hoàn toàn kết nối Supabase và lưu trữ dữ liệu online. Tất cả mọi người có thể vào chơi trực tiếp ngay trên trình duyệt mà không cần đăng nhập hay tài khoản.
- **Nhiều loại Parrot với kỹ năng độc đáo**: Sunflower (tạo Token), Pizza (bắn Pizza), Baseball (đẩy lùi), Ninja (phi tiêu crit), VR (bắn laser xuyên hàng), Royal (vương miện làm chậm), Flower (làm choáng diện rộng), Grim (bom độc 3x3).
- **Hệ thống Wave & Thời tiết**: Ngày, đêm, mưa rào với hiệu ứng thay đổi quy tắc thu thập Token.
- **Lawnmower**: Xe cắt cỏ bảo vệ hàng cuối cùng.

## Hướng dẫn chơi
1. Mở `index.html` trên trình duyệt web.
2. Bấm nút **Start** để bắt đầu.
3. Trồng **Sunflower** để thu thập Token mặt trời.
4. Đặt các loại **Parrot** để ngăn chặn Zombie tiến vào căn cứ.
